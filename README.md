# EmShell

Windows 上的服务器连接工具。深色界面，内置终端，把常用的 SSH 连接、分组、密钥和最近记录集中在一个窗口里。

## 功能

- **连接管理**：新建、编辑、删除、搜索、收藏；支持按分组归类，分组可设置标记颜色
- **连接状态**：自动检测端口是否可达，列表显示「在线 / 离线」和握手延迟
- **多标签终端**：本地 PowerShell / cmd，或直接连远端服务器；右键可复制、粘贴、全选
- **系统托盘**：关闭主窗口后驻留右下角托盘，双击图标恢复，托盘菜单退出
- **SSH 登录**：支持密码和密钥认证；保存过密码后自动填充，主机密钥会与 `~/.ssh/known_hosts` 校验
- **密钥管理**：导入已有私钥、生成新密钥、复制公钥
- **界面自定义**：深色 / 浅色配色；可选背景图，蒙层浓度可调，也可以随时停用
- **自动更新**：启动后静默检查新版本，也可以手动检查；下载校验后自动更新，失败会回滚
- **密码保护**：连接密码使用 Windows DPAPI 加密，绑定当前 Windows 账户

## 下载与安装

打开 [Releases](https://github.com/ihehe1996/EmShell/releases) 页面，下载最新版本。两种方式任选：

- **安装版（推荐）**：`EmShell-v1.0.1-install.exe`
  双击安装，可以装到 `Program Files`，自动创建开始菜单/桌面快捷方式，并在 Windows 的「应用和功能」里生成卸载项。
- **便携版**：`EmShell-1.0.1-win64.zip`
  解压到任意目录，双击 `EmShell.exe` 即可运行。

安装版会自动处理好自动更新需要的目录权限；便携版如果放在 `Program Files` 之类受保护的位置，更新时可能需要手动下载替换。

运行需要的 Qt 组件都已经打包，不需要额外安装 Qt 或 OpenSSH。

**系统要求**：Windows 10（1809 及以上）/ Windows 11，64 位。

## 快速上手

1. 点左上角 **新建连接**，填写主机、端口、用户名，选择密码或密钥
2. 保存后在列表里双击，或点右侧的 ▶ 按钮连接
3. 侧栏可以切换「所有连接」「最近使用」「收藏夹」和各个分组
4. 顶部搜索框可以按名称、主机、用户名过滤
5. 「配置管理」里可以切换配色、设置背景图、调整终端默认 Shell 和字号
6. 「软件更新」里可以手动检查新版本；程序启动后也会自动查一次

终端里 **右键** 可以复制、粘贴、全选；也可以用 `Ctrl+V`（或 `Ctrl+Shift+V`）粘贴，`Ctrl+Shift+C` 复制，`Ctrl+Shift+A` 全选。

关闭窗口后程序会驻留到右下角托盘，不会退出。

## 常见问题

**点关闭按钮后程序去哪了？**
程序最小化到了右下角的系统托盘，仍在运行。双击托盘图标可以恢复窗口；右键托盘图标选择「退出 EmShell」才会真正退出。
Windows 11 可能会把新出现的托盘图标收进任务栏的「^」溢出区，可以把它拖到任务栏上固定。

**终端里怎么复制粘贴？**
在终端里点右键，菜单里有「复制 / 粘贴 / 全选」。快捷键：`Ctrl+V` 或 `Ctrl+Shift+V` 粘贴，`Ctrl+Shift+C` 复制，`Ctrl+Shift+A` 全选。

**状态显示「在线」，但连不上？**
「在线」只表示端口可以建立 TCP 连接，不代表 SSH 用户名、密码或密钥一定正确。认证失败的信息会显示在终端里。

**延迟显示「—」？**
说明这次检测没有连上端口（离线或超时）。切换页面或稍等片刻会重新检测。

**换电脑 / 换 Windows 账户后密码要重新输入？**
密码用 Windows DPAPI 加密，密文绑定当前 Windows 账户，这是有意的安全设计。

**提示更新目录写不进去？**
便携版解压到 `Program Files` 等受保护目录时会这样；用安装版安装的通常不会。也可以到 Releases 页面手动下载新版本替换。

**卸载会删除我的连接吗？**
不会。程序卸载只删除安装目录，`%APPDATA%\Em\EmShell\` 里的连接配置、密钥索引和背景图会保留。

**数据保存在哪里？**
`%APPDATA%\Em\EmShell\`，里面包括连接配置、密钥索引和背景图。
